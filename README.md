One funny line, a single sentence of at most 200 characters, on any subject.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
I told my smart fridge about my diet, and now it just sighs and dims its light when I open it at midnight.
```
